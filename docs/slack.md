# Solunized Slack Theme

Slack no longer supports importing a theme file. It does still accept a custom theme:
a comma-separated string of 8 hex colours you paste into Slack yourself.

This document is auto-generated by `generate_themes.rb`. Do not edit by hand.

## How to set it

1. Click your profile picture, then **Preferences** → **Appearance** → **Custom theme**.
2. Paste the string for the variant you want.
3. Save changes.

Alternatively: paste the string into any message and send it. Slack shows an **Apply Slack
theme** button on the sent message, for you or anyone else in that conversation to use.

## What each value controls

These 8 roles are all sidebar elements. Slack's custom theme doesn't reach the message pane,
which keeps following Slack's own light/dark/system setting.

| Position | Slack role | Solunized colour |
|----------|------------|-------------------|
| 1 | Column BG | `bg_0` |
| 2 | Menu BG Hover | `bg_1` |
| 3 | Active Item | `blue` |
| 4 | Active Item Text | `bg_0` |
| 5 | Hover Item | `bg_2` |
| 6 | Text Color | `fg_0` |
| 7 | Active Presence | `green` |
| 8 | Mention Badge | `red` |

## Downsides

- Colours only the sidebar; the message pane won't match Solunized's background there.
- The theme is visible only to you, unless you use the message-box trick above — that
  sends the code as a plain message, readable by everyone in the conversation.
- There's no file to install — the string has to be pasted in by hand, once per account.
- Slack always draws the mention badge's count in white text. In the dark and black
  variants, no accent colour in the palette reaches the contrast small white text needs
  against a badge fill — `red`, used here, comes closest but falls short.
