# Solunized Slack Theme

Slack no longer supports importing a theme file. It does still accept a custom theme:
a comma-separated string of 8 hex colours you paste into Slack yourself.

This document is auto-generated by `generate_themes.rb`. Do not edit by hand.

## How to set it

1. Click your profile picture, then **Preferences** → **Themes** → **Custom theme**.
   (Alternatively, paste the string into any message box — Slack offers to apply it as a
   theme before you send anything.)
2. Paste the string for the variant you want.
3. Save changes.

## What each value controls

| Position | Slack role | Solunized colour |
|----------|------------|-------------------|
| 1 | Column BG | `bg_0` |
| 2 | Menu BG Hover | `bg_1` |
| 3 | Active Item | `blue` |
| 4 | Active Item Text | `fg_1` |
| 5 | Hover Item | `bg_2` |
| 6 | Text Color | `fg_0` |
| 7 | Active Presence | `green` |
| 8 | Mention Badge | `red` |

## Downsides

- Colours only the sidebar. The message pane keeps following Slack's own light/dark/system
  setting, so it won't match Solunized's background there.
- The theme is visible only to you unless you explicitly share it with teammates.
- There's no file to install — the string has to be pasted in by hand, once per Slack account.
